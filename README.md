# 🏥 Hospital Management System

This is a **Hospital Management System** built using **Python** and **MySQL** that allows administrators to manage patients, doctors, appointments, billing, and more. Designed as a terminal-based project, it provides a simple yet functional interface for understanding core database operations and backend logic in healthcare systems.

## 📌 Features

- Add, view, update, and delete patient records
- Manage doctor details and appointments
- Maintain diagnosis and treatment records
- Generate and view bills
- Secure login system for admin access

## 🧰 Tech Stack

- **Backend**: Python (with `mysql-connector`)
- **Database**: MySQL
- **CLI-based UI**: Simple terminal interface using standard Python libraries

## ⚙️ Installation

1. **Clone the repository**
   git clone https://github.com/Muxamil1920/Hospital_Management.git
   cd Hospital_Management

python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate

pip install -r requirements.txt

python manage.py runserver

🛠️ Usage
Upon running, you’ll see a text-based menu to choose different modules like Patient Management, Doctor Info, Billing, etc.

Follow the on-screen instructions to perform CRUD operations.
